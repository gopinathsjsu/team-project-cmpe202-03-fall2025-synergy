#  Project Documentation

This folder contains all required documentation for the project, including sprint reports, XP values reflection, UI wireframes, and architectural diagrams.

---

## Project Journal & Weekly Scrum Reports

All sprint documentation (Sprint 1, Sprint 2, Sprint 3, Sprint 4, Sprint 5, etc.) is stored in this folder.

Each **Weekly Scrum Report** includes:

- **Tasks completed**  
- **Tasks planned next**  
- **Blockers or dependencies**  
- **Scrum Backlog updates**  
- **Task Board story updates**  
- **Burndown Chart progress**  

These elements together form the complete Scrum-based project journal.

---

## XP Core Values Reflection

The file **XP Core Values.md** documents how the team demonstrated selected XP values throughout the project:

- Communication  
- Simplicity  
- Feedback  
- Courage  
- Respect  

Two of these values were selected and summarized as required.
